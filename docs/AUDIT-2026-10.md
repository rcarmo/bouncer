# End-to-end audit — 5 October 2026

Audited baseline: `e91841d`. The fixes and regression tests are released as `v0.1.0`, the first tagged release. No production deployment was changed.

## Fixed findings

| Area | Finding and correction |
|---|---|
| Enrollment trust | Alternative client-IP headers and a private proxy's own address could grant local bypass. Authorisation now uses the trusted, right-to-left XFF chain; missing/malformed attribution fails closed. The UI uses the same predicate and is non-cacheable. |
| Enrollment codes | Added persisted 10-minute expiry and a generation-wide 10-guess cap. Issuance is atomic; wrong origins have no token side effects; failed persistence cannot authorise enrollment. |
| WebAuthn | Require discoverable credentials. Preserve backup eligibility/state so newly enrolled synced credentials remain usable. Separate login/registration challenges and consume each challenge once. Reject clone warnings and atomically prevent signature-counter regression/replay across concurrent logins. |
| Persistence | Serialise config/session snapshot and write operations. Session reads return copies. Failed creation/user writes roll back; failed logout persistence returns an error while revoking in memory. |
| Revocation | Check that the session's user still exists with credentials in the current site. User removal takes effect for new requests after reload/restart. |
| Proxy headers | Reconstruct original client, public host and HTTPS forwarding headers after ReverseProxy's Rewrite sanitisation. Remove alternate attribution headers. Strip Bouncer's bearer cookie, retaining application cookies. |
| Backend policies | Bouncer's UI CSP and permissions policy no longer override proxied applications. |
| Streaming/reload | Select one complete routing generation per request. Prevent authentication mutations racing reload. Retain old backends for existing streams. Reject invalid reloads and changes to bound listeners/session storage. |
| Lifecycle | Initialise TLS/listeners before processing reload signals; stop/join reload processing at shutdown. Cancel/join GeoIP workers, close SQLite pools, and hold read leases through queries. Bound graceful shutdown. |
| TLS/routing | Validate CA/key material without silently replacing trust roots. Renew invalid, wrong-CA and near-expiry server certificates. Reject duplicate IDs, unknown hosts, invalid URLs and invalid RP-ID relationships. Fix IPv6/port matching and IP SAN aggregation. |
| Onboarding/CLI | HTTP trust-only page links to canonical HTTPS. Add optional `server.httpListen`. Explicit host/IP CLI overrides update WebAuthn origin; honour config onboarding. |
| Configuration | Reject invalid cookie names, unusable TTLs, and session paths that overwrite config. |
| Dependencies/build | Upgrade JWT to v5.2.2 for reachable GO-2025-3553. Update Docker Go/Alpine bases, lint tooling and test targets. Exclude live state and dependencies from Docker context. |
| Release workflow | Gate image publishing on profiled validation, embed the tag in the Docker binary, and remove automatic tag/release/run/image pruning. Untagged component digests can remain referenced by a multi-architecture manifest. |
| Test runner | Bound browser readiness and shutdown waits, drain logs continuously with a size limit, and fail on unsuccessful server exits or missing profiles. |

## Verification and allocation evidence

Every test target now uses `scripts/test-profile.sh`: uncached execution, `memprofilerate=1`, unique run directories, matching binaries, and `alloc_space`/`alloc_objects` summaries. Process/browser workloads also collect profiles from each Bouncer process. CI uploads profiles for 14 days. See `AGENTS.md`.

Passed with allocation profiles:

- `make test`, `make test-race`, and `make coverage` (51.6% total statements).
- `make test-integration` and `make test-integration-race`: real Bouncer process; unauthenticated SSE/WS denial, immediate SSE events, bidirectional WS, reload while connected, traffic beyond the 15-second read timeout, user removal, malformed reload and clean race-instrumented shutdown.
- `make test-browser` and `make test-browser-tls`: Chromium virtual resident, backup-eligible authenticator; enrollment → logout → discoverable login; browser EventSource/WebSocket; session/credential persistence after restart. TLS mode checks HTTP trust-page navigation to HTTPS. The test context accepts the generated CA; it does not install OS trust.
- `make bench TEST_PACKAGES='./internal/session ./internal/site' TEST_FLAGS='-benchtime=100x'`.

Additional checks: `make check` (vet, golangci-lint, gosec, build), `make vuln`, and `git diff --check`. Vulnerability checking reports no reachable vulnerabilities or vulnerable imported packages; it lists 37 advisories in required modules whose affected functionality is not called.

## Deployment limits

- No Docker daemon was available for image execution. Physical Apple/Android authenticators, OS trust installation, Bonjour discovery, and a live Cloudflare Tunnel were not exercised.
- Previously enrolled synced credentials may need re-enrollment: the old schema did not store backup eligibility. It cannot safely be inferred from an unverified assertion.
- Restoring older code/state can lose token expiry/guess budgets and backup flags, or revive consumed tokens/revoked sessions. Preserve current credentials and CA keys; treat state rollback as a security operation.
- Revocation applies at request admission. Existing streams survive reload/user removal until disconnected. Restart if immediate termination is required.
- Local bypass remains an explicit/default LAN trust policy. Disable it for untrusted LANs. Trusted proxies must sanitise host/protocol headers and append the observed client to XFF.
- Failed logout persistence returns an error; a crash before storage recovers can leave the old session on disk. Resolve write failures before treating revocation as durable.
- Use one writer per config/session pair. Replace configuration atomically and avoid editing it concurrently with enrollment.
- Intermediate proxies/CDNs require their own SSE/upgrade configuration. The tests verify Bouncer, not an arbitrary external proxy chain.
