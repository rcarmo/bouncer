Before installing trust, obtain the CA SHA256 fingerprint from the administrator through an independent trusted channel (for example, a known phone number or trusted server console). Ask them to run bouncer --config bouncer.json --fingerprint-CA.

This HTTP page and its fingerprint are unauthenticated and can be replaced by an attacker. They do not authenticate the CA.

Download the certificate after comparison, then compare its SHA256 certificate fingerprint in your certificate viewer before installing. Alternatively run openssl x509 -inform DER -in bouncer-ca.cer -noout -fingerprint -sha256. Stop if anything differs.

The iOS/macOS profile is unsigned and installs a root CA. Trusting it grants broad authority to authenticate TLS sites, not just Bouncer. Only install it if you trust its administrator. Inspect the embedded certificate fingerprint before approving the profile, and enable root trust only after verification.
